# Welcome to Patchli

Patchli is an open-source Linux infrastructure operations platform.

Its mission is simple:

> Simplifying Linux Infrastructure Operations.

## Current Features

- Linux Patch Dashboard
- Managed Node Inventory
- Telemetry Collection
- Documentation Center

## Vision

Patchli aims to become an integrated Linux infrastructure platform for engineers and SMBs.
